# VOXU V2：电池版与 BOM

记录日期：2026-10-18。用户指定本次产品版本为 **V2**。

V2 采用原 ESP32 开发板、原麦克风、常规款 5V UPS 充电升压一体板和 3.7V / 550mAh 电池。此版本号指 VOXU 产品方案，不是电源板上的 `V1.0` 硬件丝印，也不表示整机已经完成电气验收。外壳正在按到货实物适配；本记录不冻结尚在修改的 CAD 尺寸或覆盖生成文件。

## 版本要求

- 保留原开发板 USB-C 作为外部接口，目标为电脑连接时充电并可刷机、充电器连接时充电，拔线后自动由电池供电，无需切换供电模式。
- 支持边充边用；运行开关关闭后继续充电为待核实要求。
- 优先完成可用产品；外壳长宽或厚度允许适当调整，约 1cm 的增减可接受，不再受原 60 × 40mm 长宽硬限制。
- 依照商品说明推进设计，用户不要求在外壳设计前实测输出电压。未实测的性能不记录为已验证。

## 电气状态与尚未确认的规格

- 5V / 1A 是商品的**输出**规格，不是电池充电电流。
- 电源板背面印有 `Ichg = 300 / Iset` 及 `800mA`。此前将 300 解释为默认 300mA 的说法作废。V2 不以该误读作为电池适配依据；默认充电电流与实物电阻、芯片资料的对应仍待核实，暂按可能为 800mA 处理。
- 550mAh 电池的允许充电电流、持续／峰值放电电流仍没有明确规格证据；不能由容量或带保护板推定。早期商品候选曾为 500mAh，本版本以用户确认的 **550mAh** 为准。
- 原 ESP32 USB-C 同时承担充电与刷机，需要核对电源改线、防倒灌与 CH340C 供电；本 BOM 不是接线施工图，也不把旧 PowerBoost 接线候选当成一体板最终方案。
- USB／电池切换、关机充电、低负载持续输出、热表现和续航尚未整机验证。不承诺 4–6 小时续航。

以上电气待确认项不阻止按实物尺寸设计和打印机械试装件，但不能据此宣称整机可以直接通电使用。
