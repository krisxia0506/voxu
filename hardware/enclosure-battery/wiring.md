# 原 USB-C 电池改接候选

**2026-10-18 更新：外壳已改为到货的 V1.0 常规款 5V 一体 UPS 板，35×20×5.6mm，以及 3.7V/550mAh 电池。以下 PowerBoost 网络和 R16=10kΩ 仅为旧候选历史，不适用于新板，不能照此修改一体板。新板输入/输出隔离、充电设定、关机供电行为仍需基于实际电路核对；当前 PR 仅交付可打印机械试装设计。**

状态：用户实测节点已定位；下面是审阅用网络连接，尚未成为可直接施工的完整接线图。需要在放大图上核对引脚，再确定改接工艺和模块输入预算。

## 已确认的板上连接

照片 USB-C 朝下、天线朝上：原两端元件左端 A 连 VIN，右端 B 连 USB VBUS；USB 上电 B=5.17 V、A=4.78 V。用户确认串口桥 CH340C，定位点在左上角。用户报告 VCC16 对 3V3、VIN 均 OL，对 B 为 0.1Ω。此证据支持串口桥目前由原始 USB 5 V 供电，不能把它当作随 VIN 开关的负载。OL 不用于证明所有回灌支路已排除。

## 候选连接

| 起点 | 终点 | 条件 |
| --- | --- | --- |
| B：USB VBUS | PowerBoost 5V 输入 | 保留原 USB 数据通路；不能接到升压输出 |
| 保护电池 | PowerBoost BAT/GND | 极性、放电能力及连接器均需按实际件确认 |
| PowerBoost 5.2V 输出 | VIN / A | 原 B→A 功率支路必须断开并检查隔离 |
| 所有 GND | 共地 | 包括原 USB 地 |
| PowerBoost EN | 小开关到 GND | 接地关闭升压；充电输入不随之断开 |
| 原板 3V3 | CH340C VCC16 与 V3（4脚） | VCC16 必须先与原 USB 5V 网络隔离，按厂家 3.3V 接法处理 V3；不能直接桥接未隔离的引脚 |

选择 CH340C 与 ESP32 共用 3.3 V 电源，依据厂家统一供电电路；不再使用独立串口板。VCC16 就近保留/补充 100 nF 去耦，V3 原去耦按厂家 3.3 V 接法处理。USB D+/D−、TX/RX、DTR/RTS 和自动下载逻辑保持。不能只把 VCC16 改到 VIN 就宣称与 ESP32 完全共用 3.3 V 电源，后者仍隔着 AMS1117。

[WCH CH340 数据手册，7.6 节统一供电参考电路](https://datasheets.diptrace.com/wch/CH340C_and_series.pdf)明确允许 3.3 V 供电时 V3 与 VCC 相连。此处仍需核对实物 CH340C 引脚及其原去耦，改造后测量隔离、3.3 V 和断电状态，再连接电脑；不能依据照片位置猜测要割的铜线。

PowerBoost R16 候选改为 10 kΩ，目标充电约 100 mA。这不限制 USB 总输入电流；模块默认适配器模式、主板 USB 描述符和电脑端供电预算仍需解决。不能宣称所有 USB-A/C 端口均已兼容。

## 需要验证的结果

- 断电后确认 B 不与 VIN 或 CH340C VCC 硬短接；不得带电测电阻。
- 插 USB、运行开关关闭：输入仍可充电，ESP32 和 CH340C 电源关闭，无信号脚反向供电。
- 运行开启：3V3 正常，MacBook C-to-C 枚举、自动下载、录音、同时充电正常。
- 拔 USB：电池持续供电，无重启；重新插入可枚举。
- USB-A 充电器、USB-C/PD 充电器两种方向插接均检查；确认 CC 配置与实际输入电流。
- 小电池低电量启动/录音峰值、温升、保护动作、蓝牙距离及续航实测。

当前不需要重复已经完成的电阻测量，也不要求用户立即拆元件。机械试装可以独立推进，完整带电验收仍待这些项目完成。
