# 第6版外壳接线规划：UPS 充电，ESP32 单独刷机

底壳已升级第6版：UPS 使用硬限位与两片压片，右侧装 SS12D00G3 独立开关。用户已实测确认外置开关接 SW/G 可控制启停。打开 `preview.html` 后点击右上角“接线演示”，可逐根高亮连接、切换日常供电 / UPS 充电 / 开盖刷机场景。动画表示连接关系，不代表已验证的电流仿真。

## 连接表

| 起点 | 终点 | 说明 |
| --- | --- | --- |
| 电池原红线 | UPS B+ | 优先保留原电池插头；核对插座与插头极性，不能仅凭形状判断 |
| 电池原黑线 | UPS B− | 不与输出线混插；未确认前保持电池断开 |
| UPS OUT+ | 两芯可拔接头 J1 正极 → ESP32 VIN | 按用户选择的5V版本规划，绝不能接3V3 |
| UPS OUT− | J1 负极 → ESP32 GND | 与正极线一起可拔开 |
| 外置开关中间脚 | UPS SW | 控制线，不串电阻 |
| 外置开关任选一个外侧脚 | UPS G | 另一个外侧脚悬空并绝缘 |
| USB 充电器 | UPS Type-C | 电池充电参数匹配之后使用 |
| 电脑数据线 | ESP32 原 USB-C | 只在 UPS 输出已经物理断开后连接 |

两根新输出电源线用已购26 AWG软线，红正黑负；已有30 AWG OK线不作这两根电源主线。J1 是新增的内部两芯防反插接头，不是电池插头，也不是新的外部开关。其具体型号、安装位置与手头配件是否匹配尚未确定，先预留线长，不能宣称已经完成空间验证；选择有明确电流额定值、能覆盖5V输出负载的接头，避免裸露带电针脚。

板上 IN+/IN− 不另接，使用板载 Type-C。SS12D00G3 中间脚接 UPS SW，任选一个外侧脚接 UPS G，剩余外侧脚不接并绝缘；无需额外串电阻，不串入电池或 5V 主电源线。用户已确认按此接法启停可用。板载开关保持实测成功时的位置，具体 ON/OFF 档位尚未记录。该验证不证明关机后的反向隔离，J1 继续保留。

原麦克风接线保留。旧共口方案中的割线、拆两端元件、改 CH340C VCC/V3 不再是当前规划步骤。若原板已被实际改动，应先按改动后的电路重审，本图不能作为恢复接法。

## 断电制作顺序

1. 拔所有 USB 线，电池与 UPS 断开。电池自身引线仍有电，不同时剪切正负线，不在电芯极耳上焊接。
2. 制作 J1 红黑两芯线束，两端分别接 UPS OUT+/OUT− 和 ESP32 VIN/GND。按实际板上丝印找焊盘，不按网页示意坐标定位。逐根焊接和绝缘。
3. 确认电池插头红黑与 UPS B+/B− 对应，保持电池未插入；不要求剪掉已配好的插头。
4. 预排线束，避开卡扣、按钮、散热元件和电池；J1 开盖后应容易拔开，保留上盖与托盘抬起余量。
5. 通电前检查极性与焊点，完成下方尚缺的电气依据。当前可以备线和制作断电线束，不代表已确认可直接充电。

## 刷机的固定顺序

**拔 UPS 充电线 → 关闭 UPS → 整对拔开 J1、绝缘分开的端子 → 开盖取出主板 → 插电脑数据线到 ESP32 USB-C。**

刷机完成：先拔电脑 USB，再接回 J1，恢复装配。单纯关 UPS 开关、或者仅拔电池，都不能视为已经隔离 UPS 输出；电脑仍可能从 VIN 支路向未隔离的电源板反向供电。J1 的物理断开用于避免本方案下两个电源输出直接并联，不依赖尚未证实的内部反向阻断行为。

## 已有依据及限制

- 用户原测量：USB VBUS侧5.17V，VIN侧4.78V；CH340C VCC与USB VBUS近似连通，与VIN/3V3在该测量条件下OL。这些结果不能证明所有回灌路径已排除。
- 用户实物标注/选择：3.7V、550mAh电池，常规V1.0的5V一体板。5V/1A是输出能力，不能当作充电电流。
- 板背出现 `Ichg = 300 / Iset` 和 `800mA`；不能把300直接读成默认300mA，也不能依据550mAh容量判断允许充电电流。需要实际版本的充电设定及电池允许充/放电规格；暂不接电池与充电器进行充电。
- 开发板由VIN单独供电时，CH340C的未供电信号脚状态、反向供电及启动/录音表现仍待确认。此图没有证明串口桥在电池模式下的电气行为。
- 充电器兼容、边充边用、关机充电、低电量峰值和温升均未整机验证。
- [Espressif 官方 DevKitC 供电说明](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html)要求USB与外部电源供电方式互斥。这里只借用该原则，不将官方DevKitC电路当作用户CH340C克隆板的精确原理图。

当前交付的是可审阅的接线规划和动态说明；充电参数与整机电气验收不因绘图完成而视为已通过。
