# VOXU 一体 UPS 电池外壳 · 居中充电口版 4

外壳 **62 × 46 × 31.4mm**，含按钮高34mm。相对上一版长度增加2mm，宽高保持。外部仅保留居中的 UPS 充电口，ESP32 刷机口留在壳内。机械设计可以打印试装，电气供电隔离仍需另行确认。

[打开可旋转、分层拆解的 HTML 预览](preview.html)。单文件离线可用，拖动旋转、滚轮缩放，滑块控制拆解程度；可单独显示底座检查加固位置。电子件展示外形包络，分层动画不代表实际拆装顺序。

网页右上角“接线演示”新增分步接线图、日常/充电/刷机场景。接线说明见 [wiring.md](wiring.md)。此项仅更新网页和说明，当前打印中的第4版 STL 保持不变。

本版底座、上盖、电池托盘需重新打印；按帽、顶杆、麦克风压框与上一版相同。不要混用旧上下盖和托盘。

## 实物与结构

| 零件 | 尺寸（mm） | 放置方式 |
| --- | --- | --- |
| 常规款 5V 一体 UPS 板，V1.0 | 35.0 × 20.0 × 5.6 | 底部，USB 朝前端充电开口，元件朝上 |
| 3.7V、550mAh 电池 | 35.7 × 24.9 × 4.7 | 上方独立可拆托盘 |
| 原 ESP32 开发板 | 51.45 × 28.33 | 中层卡扣固定，PCB 底面 z=12mm；刷机口完全内藏 |
| 原 14mm 圆形麦克风 | 沿用 | 上盖声孔朝外 |

- 外部只有 UPS 充电口：前端面横向中心 y=23mm、中心高度 z=6.1mm。开口 14×8mm，给插头外壳留空间；UPS 前端距壳外 2.5mm。
- UPS 插座横向中心按照片取距板侧边 15mm 的名义位置，并非用户实测。开口留有余量，首次试装需确认插头能插到底，不要强推模块。该版居中是设计值，实物插座偏差尚未验证。
- 原 ESP32 USB 不再外露。偶尔刷机时开盖、断开电源并松开主板卡扣，将主板取出后插刷机线；不承诺板固定在壳内时可以插线。
- UPS 定位空间 36×21mm，预留 6mm 高度。底床预留 0.2mm 绝缘胶带空间，PI 胶带穿底部两组槽固定模块。
- 前方主板支撑改为跨过 UPS 的桥式支撑；靠 UPS 一侧的卡扣立柱向外退让，下部带加宽底脚和斜撑，上端接回原弹臂。另一侧保留加固立柱。弹臂和扣唇尺寸不变。
- 侧面开关窗口 6.5×7.2mm，避开卡扣立柱。使用细塑料拨棒操作；开关位置根据照片预留，实际行程和可操作性需试装。
- 电池托盘底厚0.8mm，每边0.5mm余量、上方1mm余量；用两枚 M2×4 平尾塑料自攻螺丝固定上盖。电池松贴 PI 胶带，不压紧软包。
- 侧边保留35×3mm连续走线通道。电池及托盘随盖抬起，线束需留开盖余量。

## 打印

[下载本版六件 STL 和说明 ZIP](voxu-battery-fit-prototype.zip)。文件名沿用旧版，但包内 revision 为 `integrated-ups-fit-4`。所有 STL 单位 mm，落在 Z=0；上盖和按帽已翻面。

| 文件 | 用途 | 支撑 |
| --- | --- | --- |
| `stl/base.stl` | 底座、主板夹臂、一体板定位和开关窗口 | 开启；清理夹臂下方和底部穿带槽 |
| `stl/lid.stl` | 上盖、麦克风座、托盘柱、BOOT 导向 | 关闭 |
| `stl/battery-tray.stl` | 550mAh 电池托盘 | 关闭 |
| `stl/button-cap.stl` | BOOT 按帽 | 关闭 |
| `stl/button-pin.stl` | BOOT 顶杆 | 开启 |
| `stl/mic-clamp.stl` | 可选麦克风压框 | 关闭 |

P2S、0.4mm 喷嘴、0.2mm 层高、3 道墙、15% 填充、Generic PLA 已完成诊断切片。上下盖不要与旧 40mm 宽版本混装。建议先打印底座和电池托盘检查就位，再打印上盖；按钮/压框可核对旧件尺寸后复用。不要为了塞下电池而磨薄其包装或压缩电池。

切片器仍出现 `Invalid T command (T65535)` 日志，虽各件 result.json 均返回 Success，本包只交付 STL，不交付生成的 G-code；请在 Bambu Studio 使用自己的机器和耗材预设重新切片。

## 不带电试装顺序

1. 清理底座支撑，铺背面绝缘；一体板先放底部定位槽，确认开关窗口对齐，再用 PI 胶带固定。
2. 从侧面走线通道预排线束，再放原开发板；四角支撑和侧面卡扣就位，刷机口留在壳内。
3. 将电池放托盘，出线靠 USB 一端，松贴胶带固定。两枚 M2×4 螺丝固定托盘到上盖，不压电池。
4. 安装原麦克风、按帽和顶杆，预留开盖线长，合盖检查 BOOT 回弹、卡扣、USB 插头和开关操作。
5. 四角 M2×8 加固螺丝是可选的，可沿用原件；不要用长螺丝替代托盘的 M2×4。

不要求用户重复测量输出电压。机械设计按产品说明和实测外形推进；**板背充电标注与 550mAh 电池是否匹配、刷机时开发板和 UPS 的供电隔离仍未完成**，机械通过不代表可以直接连电池充电。

## 验证与复现

`validation.json` 检查六件封闭网格、正体积、单连通；主板/电池/模块/托盘/螺钉头碰撞、托盘随盖拆出、按键动作、卡扣保持与释放、麦克风通孔、走线通道和开关窗口。电子板用保守包络代替全部小器件，插头伸出和柔性线束未作完整仿真。固定强度、打印公差和实际开关手感需试装。
