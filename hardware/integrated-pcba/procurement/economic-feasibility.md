# 经济型降本核算与制作暂停条件

核查日期：2026-10-24。用户最终要求：两块完整焊接 PCBA 合计 **160 元硬上限**，全部厂家焊接，超出暂缓制作。新电池按此前要求另计，但仍必须先列清；不付款。未提交新的 PCB 或 SMT 订单，原 Y5 未付款，旧 SMT 草稿不提交。

## 结论

**尚未找到满足预算且保留全部功能的经济型方案。未完成经济型电路/PCB 改版，也没有新的完整成品实时报价。** 以下为选型门槛核算，不是可生产 BOM 或最终账单。现有 A2 源文件和 3D 备份继续保留，禁止将其视为经济型新版。

现有固件要求 Bluetooth Classic HFP + HID。不能用便宜的 ESP32-C3/S3 直接替代；其不支持 Classic，见 [乐鑫 Bluetooth 架构表](https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/api-guides/bt-architecture/overview.html)。改裸芯片还需要 Flash、晶振、射频匹配和天线设计验证，并非更换一个封装。

## 硬上限复算与暂停依据

即使暂按PCB券完全抵扣板费，现有PICO候选的185.20元小计本来就未包含PCB，所以不会因只拿到PCB券而降到160元内。

另用本日已查的更低价裸芯片ESP32-D0WDQ6核算：若保留现选数字麦克风、USB-C及电池插座，并按四种非免换料料号计算，则工程50 + 换料4×20 + 两颗主控2×14.42 + 两颗麦克风2×4.64 = **168.12元**。此处连连接器本身、Flash、晶振、射频、电源、其余元件、焊点、损耗和运费均未加入；不是完整报价，也不是所有可能设计的理论最低价。它说明当前已查候选路线即使阻容全部免换料，仍不能满足160元。

因此继续保持制作暂停；没有以未完成的替代BOM提交订单。全功能合格经济型改版和完整实际总价仍未取得，不声称完成。若要继续寻找不同主控/模拟麦克风/电源架构，须重新评估功能和录音性能，不能将当前小计包装为可下单方案。

## 后续降本门槛及未完成项

1. 首先确认经济型可贴主控；保留 Classic 功能。只有成本表可落在160元内才进入该路线完整改版。
2. 优先消除不必要扩展料号：2.21k/8.66k电阻改常用基础库阻值须重算LED/充电电流；电容统一基础库须核对偏压后有效容量和电源稳定性；不能只按标称容量替换。
3. 原21.55元 Coilcraft 电感是重点降本项；替代须满足饱和电流、温升电流、DCR和开关频率，不能换成普通射频0402电感。
4. UART便宜替换不能丢失USB限流控制、断电隔离；CP2102N配置及烧录成本仍待闭合。充电器须保留合规电流与真实电池温度监测。
5. 全部开关、Type-C和电池连接器都必须厂家焊好；不把手焊元件从报价删掉来满足预算。Type-C短边居中继续保留。
6. 最终费用必须逐项列出：最低PCB批量、两块装配、采购损耗/MOQ、换料、工程、钢网、检测、包装运费、烧录及电池。未知项保持未知，不填零。160元上限不得以多做板子后摊薄单价代替。
