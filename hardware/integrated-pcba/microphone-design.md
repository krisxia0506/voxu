# A1 INMP441 麦克风子电路

状态：子电路设计，不是整板生产发布。采购优先 INMP441；仅无法取得可装配物料时才设计 MSM261S4030H0R 版本。不可将两者封装直接互换。

## 网络连接

| INMP441 引脚 | 信号 | 连接 |
| --- | --- | --- |
| 1 | SCK | ESP32 GPIO26 |
| 2 | SD | ESP32 GPIO33；R1=100kΩ 下拉至 GND |
| 3 | WS | ESP32 GPIO25 |
| 4 | L/R | GND，左声道 |
| 5、6、9 | GND | 连续地；不遗漏外壳/地焊盘 |
| 7 | VDD | 系统 3V3；C1=100nF，就近跨 7/6 脚 |
| 8 | CHIPEN | 3V3；本版不新增电源状态固件 |

R1 优先 0603/1%，C1 优先 0603/X7R/10V 或以上、容差 10%；实际嘉立创料号待全板 BOM 合并，避免引入独立料种。原理图的 3V3、GND、GPIO 标签为主板连接边界，不代表增加模块插座。

## 与当前固件的关系

`firmware/hfp-probe/src/main.c`：MIC_RATE=16000，Philips I²S、32bit、左声道，GPIO26/25/33。本电路保留该映射，无固件改动。

麦克风要求每帧 64 个 BCLK；16kHz 对应 1.024MHz，落在手册范围内。实际 ESP-IDF 单声道配置生成的时钟仍需在样板用逻辑分析仪核验，不能仅凭 MONO 名称认为每帧只有 32 位。

按手册 3.3V 条件计正常典型 2.2mA、最大 2.5mA。之前提到的 1.4mA 对应 1.8V。CHIPEN 为高且停时钟时为待机，并非最低功耗的关断状态。恢复时钟后存在数据稳定时间，应在整机验收观察首段音频。

## 布局与制造

INMP441 是底部进音，按原厂推荐 land pattern 设置声孔、阻焊及钢网。不可把模块的六针布局当成芯片的九焊盘封装。VDD 去耦和 SD 下拉靠近麦克风，I²S 短线且具有连续参考地；麦克风远离电感和按钮承力点。电池不遮挡声孔。

未冻结声孔尺寸、钢网开口与封装库，避免从照片猜尺寸。回流、吸嘴位置和清洗限制随工厂装配说明交付。首版不使用两种麦克风共用的叠加焊盘。

## 验证边界

必须检查九个芯片焊盘全部连通、去耦跨 VDD/GND、下拉跨 SD/GND，并确认 3V3 与 GND 未短接。软件连接检查不替代 ERC、封装检查、DRC 或样板音频实测。

原厂 DS-INMP441-00 rev1.1，第 4 页供电，第 5 页时序，第 8 页引脚，第 11 页数据接口；本次从 [Mouser 托管的原厂手册](https://www.mouser.com/datasheet/2/400/INMP441-1112508.pdf)核对。布局原则另参见 [乐鑫硬件指南](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32/pcb-layout-design.html)。
