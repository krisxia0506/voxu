# E1 经济型电气候选：超预算，未放行

核价日期：2026-10-24。目标为两块全部厂家焊接、合计160元以内，不付款。新电池按已确认要求单列。当前没有满足此目标的完整可生产方案；本目录不能下单制造。

## 已落实的改动

- 主控由WROOM-32E改为ESP32-PICO-V3（C967022，7×7 mm TFQFN48-EP）。依据[乐鑫数据手册v1.4](https://www.espressif.com/sites/default/files/documentation/esp32-pico_series_datasheet_en.pdf)映射电源、启动、UART、GPIO26/33及保留脚，保留经典蓝牙HFP/HID所需的ESP32架构。4MB Flash与晶振集成，但仍需PCB天线和匹配验证。
- 保留PDM麦克风、单USB-C充电/下载、电池电源路径、关机充电、USB域断电隔离。Type-C短边居中的机械要求继续有效；E1尚无新布局，不能把A2预览当成E1。
- 阻容优先采用基础库；ISET由8.66k单电阻改为8.2k+470Ω串联。含1%容差的最大电阻8756.7Ω，低于所引用的8900Ω推荐上限；沿用电流系数容差的充电电流计算为91.02–113.59mA。
- 增加局部去耦、Flash电压启动下拉及初始RF串联0Ω位置。共71位号、29料号。RF的0Ω只是调试初值，两个并联调谐位置暂不装，不能宣称无需射频调试。
- A2原生EDA工程、PCB和STEP备份保留。这里的KiCad原理图是交换草稿，尚未导入/验证为立创EDA专业版原生工程。
