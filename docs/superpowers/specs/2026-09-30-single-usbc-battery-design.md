# VOXU 单 USB-C 电池版设计规格

日期：2026-09-30。基线：`81804c4`（已合入 PR #3 外壳与 PR #4 自动重连）。

**状态：待用户审阅的设计规格；尚未生成电池版 CAD、STL 或完成电气实测。**
本文中的尺寸和工作指标是后续实施的输入，不是实测结果。原 USB 版模型继续保留。

## 1. 已确认的目标

- 复用现有 ESP32-WROOM-32、30 针 USB-C 开发板及 14 mm 圆形 INMP441。
- 不更换主控，不丢失 BOOT 开始/结束操作和上次蓝牙设备自动重连功能。
- 电池运行目标为持续连接、使用麦克风约 4–6 小时；接受外壳加大。
- **复用开发板现有 USB-C 接口**进行充电、供电与刷机，不在外壳增加充电口。
- 支持接充电器时边充边用，以及关闭麦克风整机时充电。
- 交付明确料号的 BOM、接线/装配说明、可编辑 CAD 生成脚本、STL、实际 CAD 预览和打印包。
- 使用 P2S；延续平面上盖、麦克风固定座、BOOT 导向按键、可解锁卡扣与可选螺钉加固。

## 2. 实物证据与设计边界

用户实测开发板 51.45 × 28.33 mm、USB-C 前端突出 PCB 约 2 mm。照片可见 VIN、3V3、EN、BOOT、PWR、D2，布局符合 CH340 USB-C 的 30 针 DevKit V1 类板。

[Micro Robotics 板型资料](https://www.robotics.org.za/development-boards/ESP32-DEV)给出 51.5 × 28.5 mm、30 针、CH340 和 USB-C；作为板型识别参考，不代替用户尺寸。
[同类板实物追线记录](https://diyelectromusic.com/2024/12/07/esp32-wroom-mozzi-experimenter-pcb-design/)给出 USB VBUS → SS14 → VIN → 3.3 V 稳压器的电路，也明确存在 USB 与 VIN 直连的变体。

因此按下面的**电气节点契约**设计，不能仅凭网络图片指定用户板上的某个器件一定要拆。焊接前核对实际电源网属于装配验收项，不阻止 BOM、CAD 和说明的制作。

## 3. 选型与取舍

选择 **BQ24074 负载分配充电板 + PowerBoost 1000 Basic 升压板**。此前讨论的 PowerBoost 1000C 不再作为本版默认件。

| 方案 | 判断 |
| --- | --- |
| BQ24074 + 独立可关断升压板 | 本版基线；有公开原理图和 PCB，充电、输入限流、温度检测及系统开关各自可控；代价是两块板和较大的外壳 |
| PowerBoost 1000C 一体板 | 集成度较高，但默认充电/输入电流不能直接当作普通电脑 USB 端口已授权的大电流负载；本版不采用 |
| 定制充电升压 PCB | 可以进一步减小体积，但需要打板和电气验证；不作为这一轮工程样机的前提 |

## 4. 电源连接与单口改造

```text
                         原板 USB 数据线 ────────── 原 USB-UART / ESP32
现有 USB-C VBUS
      │ RAW_USB_5V（必须只来自外部 USB）
      ▼
BQ24074 VBUS ── 输入电流控制 / 负载分配 ── OUT（约电池电压至 4.4 V）
                     ↕                            │
               LIPO / BATT                        ▼
               保护电池                 PowerBoost Basic 输入 BAT
                                                  │ 约 5.2 V
                                                  ▼
                                        SYS_5V → 开发板 VIN
                                                  ▼
                                        原板稳压器 → 3V3 → ESP32 / INMP441
所有 GND 共地
```

必须满足以下约束：

1. 将原来 RAW_USB_5V 到系统 VIN 的直供通路断开。若经串联二极管连接，可在确认两侧网络后拆下该器件，将 USB 侧作为充电输入、系统侧作为升压输出；若是直连版本，需单独确定可恢复的隔离改造位置。不得仅增加一条充电飞线而保留闭合回路。
2. 升压输出只接系统 VIN，不能接 RAW_USB_5V，不能接充电板 VBUS，也不能接 ESP32 3V3。电池不得直接接开发板 VIN 或 3V3。
3. 原板 USB-UART 的供电必须追线记录：若来自系统电源，保留；若来自 RAW_USB_5V，需验证关机时 TX/DTR/RTS 不会向已断电的 ESP32 灌电，必要时一并迁移其供电到合适的系统电源节点。不能在未验证前宣称关机完全断电。
4. 保留 USB D+/D−、CC 下拉及原有自动下载电路；不把数据线引到充电板的 USB 数据焊盘。充电板自带接口不再对外开放，避免第二路外接电源。
5. BAT/LIPO、OUT 和 VBUS 是不同网络。必须按实物丝印复核电池插头极性；同为 JST-PH 不保证正负一致。
6. RAW_USB_5V 与 SYS_5V 的隔离、电源极性和短路检查通过后，才能首次连接电池；初次上电先用限流电源进行无电池调试。

## 5. 操作、限流与开关

为避免默认从电脑 USB 抽取充电大电流，本样机采用一个明确的 **PC / CHARGE** 模式开关。它不自动检测 USB 电源能力。

| 状态 | BQ EN1 | BQ EN2 | 行为 |
| --- | --- | --- | --- |
| PC（默认） | 高 | 高 | BQ 输入进入 standby，OUT 由电池供电；USB 用于数据，不从电脑给电池充电。刷机需电池有电且运行开关 ON |
| CHARGE | 高 | 低 | USB 输入限流档 500 mA，优先系统负载、剩余电流充电；接 5 V ≥1 A 充电器。不要在普通电脑口选此档 |
| 无 USB | 不改变 | 不改变 | 运行开关 ON 时使用电池；无需切换模式 |

按 #4755 原理图：SJ2 为 EN1、SJ1 为 EN2；两者 1 号焊盘接 OUT，2 号为控制节点，3 号接 GND。断开默认连接后，将 EN1 固定为高；EN2 接模式开关公共端，两端接 OUT/GND，另加 10 kΩ 上拉至 OUT。最终接线图必须同时给出焊盘朝向图，不只列编号。

充电电流跳线改为 **0.5 A**（先断开默认 1.0 A 跳线，再连接 0.5 A）。输入 500 mA 和电池充电 500 mA 是两项不同限制；运行时实际充电电流会降低，不承诺满速充电。PC 档不能在电池耗尽时启动整机，需先切 CHARGE 档接充电器恢复电量。

运行开关：公共端接 PowerBoost EN，OFF 端接 GND，ON 端悬空并利用板上默认上拉；它关闭升压输出，充电板和电池保护仍工作。这不是运输/维修用电池物理隔离；拆装前拔下电池和 USB。

切断充电板 THERM 默认旁路，按厂家指南接 10 kΩ NTC 到 THERM/GND。温度检测和电池保护都必须实际验证，不将充电芯片热限流当作电池温度保护。

## 6. 续航与热设计预算

电池名义能量为 2.5 Ah × 3.7 V = 9.25 Wh。初估升压效率取 85%，可用容量取额定的 80%，系统输入取 5.2 V：

`估算小时 = 2.5 × 3.7 × 0.85 × 0.80 / (5.2 × 实测系统平均电流A)`

| 系统 5.2 V 平均电流（包含开发板与麦克风） | 初估续航 |
| --- | ---: |
| 0.20 A | 6.05 h |
| 0.25 A | 4.84 h |
| 0.30 A | 4.03 h |

这些电流不是已有测量。若实测平均电流高于约 0.30 A、低温/电池衰减或转换损耗使连续工作不足 4 小时，目标未达成，必须优化耗电或增加容量并重做电池仓。

充电器档下应确认平均电池电流确实流入电池；单看充电灯不能证明“边充边用”。500 mA 输入档供应不足时 BQ 会由电池补充，不能将此状态算作达标。实测全负载/充电温升、供电波形及录音噪声；软包与热源之间设置独立隔板和空气间隙。

## 7. 外壳布局与外观

外形为圆角方盒、平面上盖，顶部保留 BOOT 按帽与 9 孔拾音区，侧面为原 USB-C、运行开关和 PC/CHARGE 开关；通过小窗口查看电源/充电状态。避免把升压板电感放在麦克风旁。

初始 CAD 占位包络 **约 80 × 88 × 42 mm**，不是最终打印尺寸。相比先前 90 × 65 × 33 mm 的口头草案，这是按两块电源板、电池分层和天线避让调整后的输入。若 CAD 能在满足间隙的前提下缩小则收紧，不能以缩小外壳为理由压迫电池。

- 底层：独立电池浅仓，预留电池制造公差、软包非挤压间隙、保护板与 JST 线出口，使用可拆固定带；螺钉、焊脚、卡扣和工具释放路径均不能进入电池包络。
- 上层前区：沿用原 ESP32 的 USB 对位、PCB 边缘固定和 BOOT 导向的相对位置，模块去排针焊线。
- 上层侧区：BQ24074 与升压板分区固定，保留其连接器实体、元件高度和线材弯折空间。外壳不为充电板自带 USB/DC 插座开孔。
- 主板天线端预留无金属区域，初始按距电池/导线/电源板至少 15 mm 的空间设计；最终参考 ESP32 模组天线布局指南逐项检查，不能只检查 PCB 彼此不相交。
- 麦克风仍贴上盖，PCB 声孔朝外；保留现有已验证的卡槽与可选压框、2.4 mm 声孔。
- 采用可解锁卡扣和可选螺钉加固；电池仓与电子件间用可拆托盘隔离。只交付实际装配零件，不增加无关试块。
- STL 按打印方向落在 Z=0；上盖外平面贴板打印。底座、托盘及各卡扣的支撑需求必须通过 P2S 切片检查后写入说明。

## 8. 实施产物与验收

后续新增 `hardware/battery/`（BOM、接线、装配、电源证据）与 `hardware/enclosure-battery/`（参数、生成脚本、STL、验证、预览、ZIP），更新根目录文档指向两个版本。不得把 USB 版 STL 覆盖成电池版。保持现有音频/按键/重连固件行为；本版不加入未经校准的电量百分比显示。

### 可以在本地完成的验证

1. CAD 生成可复现；所有零件封闭、正体积、法向一致、连通性符合实际零件数。
2. 组件实体与外壳/托盘、走线、电池保护空间、天线避让区无非预期干涉。
3. USB 插头插入、开关全行程、BOOT 行程、上盖合装与释放、螺钉长度及麦克风声孔贯通检查。
4. P2S 切片验证全部需打印零件，区分需支撑与无需支撑；只交付 STL/源码/预览，不将未验证 G-code 作为成品。
5. 打印包清单与当前 CAD 参数一致，链接和文档一致；现有两项固件主机回归继续通过。

### 必须由实物证明的验收

1. 原板电源网与隔离点已确认；电池供电时 USB VBUS 无可驱动的反向电压，充电输入不被升压输出回灌。
2. 空载、开机、蓝牙重连、持续采音和 USB 插拔状态供电稳定，无欠压复位；USB 刷机和 BOOT 操作正常。
3. CHARGE 档下持续使用麦克风且电池净充电；OFF 档整机退出运行、仍能充电；PC 档充电输入确实关闭。
4. 电池 NTC 温度保护、充电终止、保护板低压切断/恢复以及系统关机行为符合器件规格。
5. 连续蓝牙麦克风使用至少 4 小时；完整记录负载、时间、电量终点、平均电流、环境/电池/电源板温度，不将计算值替代实测。
6. 实物装配不卡线、不压电池；USB 插接、按钮回弹、开关操作、卡扣拆装和蓝牙距离/音频噪声通过比较验证。

本地几何通过、切片成功、电气实测与续航达标分别报告。任何未完成项保留为未完成，PR 保持 Draft，不把设计资料可下载表述为整机已经验证完成。
